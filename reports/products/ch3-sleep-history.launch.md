# ch3-sleep-history — launch gate (27.10.2026)

Продукт: ch3 — sleep-history форматы (длинные документальные истории 60–120 мин, стоковое видео + ACE-Step фон) на отдельном канале (один Google-аккаунт = один канал). До GO публикация заблокирована гейтом `scripts/launch_gate.py ch3-sleep-history` в воркфлоу ch3 (когда появится); пилот делается в private/unlisted, канал публично не меняется.

## Счётчик открытий по получателю
Получатель = YouTube-зритель US, sonnа / sleep / relaxing history niche. Воронка и источник каждой цифры:
1. **Показы превью (impressions)** — YouTube Reporting API bulk-отчёт `channel_reach_basic_a1`, поле `video_thumbnail_impressions` (per video, per day); требует scope `yt-analytics.readonly` — токен перевыпустить до GO. Скрипт снапшота переиспользует `pipeline/ch2_snapshot.py` (адаптирован под ch3 id).
2. **CTR показов** — тот же отчёт, `video_thumbnail_impressions_ctr` (суточный срез).
3. **Просмотр (view)** — YouTube Data API `videos` / Analytics v2 `views` по видео (увидено в снапшоте и yt-dlp как прокси-проверка).
4. **Удержание 30 с / 50%** — Analytics v2 `averageViewPercentage` per video; порог «в разбор»: long < 25% avg (спящая аудитория уходит раньше), Short < 40% avg. Отдельной метрики «удержание на 30-й секунде» через API нет — прокси: среднее удержание.
5. **Подписка** — Analytics v2 `subscribersGained` per video (`metrics=subscribersGained, dimensions=video`).
6. **Источник трафика** — Analytics v2 `dimensions=insightTrafficSourceType` per video (SEARCH/RELATED_VIDEO/BROWSE/SHORTS_FEED...), суммарно views по источнику.
Снапшот: воркфлоу `ch3-snapshot.yml` (клонирован из ch2-snapshot), cron ежедневно 12:30 UTC + dispatch; вывод в лог шага и `reports/ch3_snapshot/<date>.md`.

## Премортем (прошлые инциденты и реальные риски — до публикации)
1. **Нет отдельного Google-аккаунта для ch3**: один email = один канал; ch2 живёт плейлистами на ch1. Создание нового аккаунта требует headful Chrome на ПК + QR верификация (browser-account-signup skill). Блокер: аккаунт не готов к загрузке — пилот готов, загрузка заблокирована.
2. **Pexels/Pixabay API ключи отсутствуют в секретах**: в ACCOUNTS.md нет записей, в GH secrets/vars — нет. Нужен ключ Pexels (бесплатно, заявка на pexels.com/api) и Pixabay (бесплатно, pixabay.com/api/docs). Без ключей — нечего скачивать сток, пайплайн встанет на шаге загрузки ассетов.
3. **ACE-Step (GPU ПК) health check падает**: `curl http://ace-step:8001/health` из контейнера даёт 000 (нет маршрута в comfynet); локально на ПК тоже 000. xl-probe.yml использует `http://ace-step:8001` внутри comfynet — если сеть не поднята, генерация фона упадёт. Нужен smoke-тест перед запуском пилота.
4. **Router LLM доступен (9router.pxbt.app), но auto-worker-combo стримит чанками** — нужен non-streaming вызов для скриптов (header `Accept: application/json` или параметр stream=false). Исправляемо в коде вызова.
5. **YouTube токен без yt-analytics.readonly** — показы/CTR не измеряются (403 Reporting API). Для ch3 GO токен нужно перевыпустить с scope (как для ch2).
6. **Kill-критерий опирается на показы, а показы не измеряются** — до перевыпуска токена гейт не может сработать. Принято прокси-режим (как ch2): выборка ≥5 роликов, ≥100 просмотров/48ч (Data API), kill по удержанию <25% (long)/<40% (Shorts), 0 роликов с ≥100 просмотров за 14 дней = NO-GO.
7. **Синтетик-флаг YouTube (containsSyntheticMedia: True)** — ACE-Step фон + edge-tts + сток = почти гарантированный флаг. Риск: ручная проверка «сделано ИИ» понижает охват. Смягчение: мониторинг impressions в снапшоте, разнообразие голосов и промптов.
8. **TTS-голос edge-tts без эмоций** — монотонная озвучка снижает удержание. Фиксация: ротация голосов (Guy/Andrew/Christopher Neural) между абзацами уже в коде; avg retention в снапшоте. Апгрейд вне скоупа.
9. **Авторские права на сток**: Pexels/Pixabay лицензии разрешают коммерческое использование без атрибуции (проверено 2024). Лог лицензий сохранять в артефакте `licenses.json` (url, author, license_type, downloaded_at).
10. **Длина 60–120 мин без мидроллов до монетизации** — не блокер запуска; реальный риск удержание <25%. Контроль: хронометраж скрипта ≥ 3600 с (validate_script).
11. **Дубли тем**: темы из breakout-сканирования коммитятся в `.state/ch3_topics_idx.txt`, проверка `test_ch3` против повторов чаще раза в 30 дней.
12. **Часовой пояс публикации**: 16:30 UTC = 12:30 ET — US день, окно корректное. Cron в будущем воркфлоу.
13. **YouTube загрузка private/unlisted**: токен загрузки (YOUTUBE_TOKEN_JSON) — тот же что ch1/ch2; область видимости канала ограничена правами токена. Private загрузка работает (проверено ch2 dryrun 24.10 run 40059754402).
