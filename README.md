# aicontent-factory

Автономный конвейер генерации и публикации ИИ-контента для пассивного
дохода. ТЗ и план — `docs/PLAN.md`. Решения по развилкам — `docs/DECISIONS.md`.

Статус: инициализация (см. kanban-доску `aicontent-factory`).
## Публичный статус репо и гейт merge

Репо `mytab0r/aicontent-factory` — **PUBLIC**. Причина: branch protection с
обязательными проверками (required status checks) доступен на GitHub Free
только для публичных репозиториев; на приватном репо API возвращает 403
«Upgrade required» (проверено 2026-10-25).

Следствие: **бизнес-код и CI-пайплайн видны всем.** Секретов в коде нет —
гит-аудит `gitleaks` по всей истории: 0 реальных находок.

Гейт merge: merge в `master` только при зелёной проверке `test`. Push без
зелёного `test` отклоняется; REST-merge раньше прохождения проверки возвращает
405 (проверено). Не мержить вручную при pending-проверках.
